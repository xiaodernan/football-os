# FOOTBALL OS

## Autonomous Long-Term Product Development Master Specification

你现在不是在完成一个普通 Web 项目。

你要长期负责从 0 到 1 构建一个大型、可扩展、AI-native、数据驱动的综合足球平台：

# FOOTBALL OS

定位：

> **The Operating System for Football.**

核心理念：

> **WATCH. UNDERSTAND. TRAIN. PLAY. MANAGE. BECOME.**

FOOTBALL OS 将现实足球世界、足球数据、新闻、战术分析、个人训练、AI 足球教练、球员成长、比赛视频分析、足球经理模拟、球探、球队管理和足球社区统一到一个产品中。

它不是：

* 新闻网站
* 足球比分 App
* FM 克隆
* FC 克隆
* AI Chatbot
* 健身 App
* 视频分析工具

而是：

> **一个连接 Real Football、Personal Football、Football Simulation 和 Football AI 的统一平台。**

---

# 0. 最高优先级原则

所有开发行为必须遵守以下原则。

## PRINCIPLE 1 — BUILD SMALL, ARCHITECT FOR SCALE

不要一开始构建几十个微服务。

先做：

```text
Next.js
FastAPI
PostgreSQL
pgvector
Object Storage abstraction
```

根据实际瓶颈逐步增加：

```text
Redis
Workers
Search
Event Bus
Java Spring Boot
Dedicated ML Services
Video Processing Workers
```

禁止为了“看起来像大型项目”提前引入复杂基础设施。

---

# PRINCIPLE 2 — REAL PRODUCT OVER MOCK UI

所有核心功能都必须真正工作。

禁止：

```text
漂亮 Dashboard
+
假数据
+
按钮点击
+
没有真实业务逻辑
```

允许：

```text
Demo Data
```

但必须明确标记为：

`DEMO DATA`

不能欺骗用户。

---

# PRINCIPLE 3 — EVERY FEATURE MUST BE VERIFIABLE

每完成一个功能必须：

1. Build
2. Run
3. Test
4. Inspect
5. Fix
6. Re-run
7. Screenshot / visual validation when applicable

不要一次性修改几千个文件然后假设系统正常。

---

# PRINCIPLE 4 — RESEARCH BEFORE IMPLEMENTATION

对于重要功能：

1. 调研现实世界产品
2. 调研竞品
3. 调研用户流程
4. 调研技术方案
5. 调研数据来源
6. 调研版权 / licensing / privacy 风险
7. 形成 ADR
8. 再实现

重点研究：

* EA SPORTS FC
* Football Manager
* FIFA Training Centre
* Tonsser
* FotMob
* Sofascore
* OneFootball
* StatsBomb
* Opta
* Sportradar
* TransferRoom
* 现代 AI football analytics 产品

不要复制其受版权保护的 UI、代码、素材或品牌资产。

研究其：

* Product philosophy
* Information architecture
* User workflow
* Interaction model
* Feature design
* Data model
* Engagement loop

然后原创实现。

---

# PRINCIPLE 5 — LEGAL DATA FIRST

现实足球数据具有版权、商标、肖像权、数据库权和授权问题。

禁止：

* 爬取受版权保护的付费数据库
* 未授权复制比赛视频
* 未授权复制球员照片
* 未授权复制球队 Logo
* 未授权复制 FC/FM 数据
* 伪装成官方产品
* 使用 EA / Football Manager / FIFA 的 proprietary assets

MVP 使用：

* 合法开放数据
* 获授权数据
* 自己生成的 simulation data
* 用户上传数据
* 用户原创内容
* 合法新闻 API
* 官方公开信息的合规引用
* 原创视觉资产

所有 Data Provider 必须通过 abstraction layer 接入。
